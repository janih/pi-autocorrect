# Project rules — pi-dev-autocorrect

- This is a pi agent extension. Entry point: `index.ts` (default-exported factory receiving `ExtensionAPI`). Support code lives in `lib/`.
- `lib/` must stay dependency-free (no pi imports) so tests can run with `node --test` / plain `node` using native type stripping.
- Relative imports use explicit `.ts` extensions (matches pi's official extension examples and jiti).
- `dict/british-english` is user-provided; do not edit.
- `dict/tech-words.txt` is GENERATED by `tools/update-tech-dict.mjs` (`npm run update-dicts`); never hand-edit it — personal/project words go in `dict/custom-words.txt` or the user's `~/.pi/agent/pi-autocorrect.json`.
- Run `npm test` and `npm run typecheck` after changing `lib/` or `index.ts`.
- The tokenizer intentionally skips code spans, URLs, paths, flags, and identifier-style tokens; when touching it, keep those cases covered in `test/spellcheck.test.mjs`.
